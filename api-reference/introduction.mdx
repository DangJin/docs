## 认证方式

API 支持两种认证方式：

### Bearer Token 认证

大部分 API 端点使用 Bearer Token 认证：

```json
"security": [
  {
    "bearer": []
  }
]
```

在请求头中添加：
```
Authorization: Bearer YOUR_TOKEN
```

### Basic 认证

部分回调接口使用 Basic 认证：

```json
"security": [
  {
    "basic": []
  }
]
```

## API 分类

### 图像生成 API
- **创建任务**: 提交图像生成任务
- **查询任务**: 查询单个任务的执行状态和结果
- **查询列表**: 分页获取任务列表

### 视频生成 API
- **创建任务**: 提交视频生成任务
- **查询任务**: 查询单个任务的执行状态和结果
- **查询列表**: 分页获取任务列表

### 回调接口
- **转码回调**: 接收超分转码完成通知
- **AI 回调**: 接收 AI 处理完成通知
